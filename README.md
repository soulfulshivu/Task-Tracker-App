# Task Tracker App

## Overview

The **Task Tracker App** is a web development project designed to help users manage their daily activities and stay organized. It provides an interactive platform where users can create, update, complete, and delete tasks through a simple and user-friendly interface.

The application focuses on making everyday task management easier, more organized, and efficient.

## Features

- **Add Tasks:** Create new tasks with ease.
- **Edit Tasks:** Modify existing task details.
- **Delete Tasks:** Remove tasks that are no longer needed.
- **Mark as Completed:** Track completed and pending activities.
- **Interactive UI:** Simple and intuitive user interface.
- **Responsive Design:** Accessible across different screen sizes.
- **Dynamic Updates:** Task lists update automatically after user interactions.

## Technologies Used

- HTML5 – Structure of the application.
- CSS3 – Styling and responsive layout.
- JavaScript – Application logic and interactive functionality.

## How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/Task-Tracker-App.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Task-Tracker-App
   ```

3. Open `index.html` in your web browser.

4. Start adding and managing your tasks!

## Working of the Application

1. Enter a task in the input field.
2. Add the task to the task list.
3. Edit or delete tasks whenever required.
4. Mark tasks as completed once they are finished.
5. Track your pending and completed activities.
